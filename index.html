GitHub Pages + 실시간 DB 연결 상태

Firebase 연결 키 적용 완료 (music-e3526)

이 파일에는 본인의 Firebase 프로젝트 연결 키가 이미 내장되어 있습니다. 그대로 index.html로 저장해 GitHub에 올리시면 됩니다.

필수 확인 1. Firebase 콘솔 설정

1) 보안 > Authentication > Sign-in method에서 익명(Anonymous)을 사용 설정 후 저장

2) 데이터베이스 및 스토리지 > Firestore Database 생성 후 [규칙] 탭에서 allow read, write: if request.auth != null; 허용 후 게시

필수 확인 2. GitHub Pages 배포

이 코드를 index.html 이름으로 저장해 GitHub Public 저장소에 올린 뒤, Settings > Pages에서 Branch를 main으로 설정하세요.
